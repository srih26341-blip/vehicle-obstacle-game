# Vehicle Obstacle Game

## About the Project
Vehicle Obstacle Game is a Unity-based game where the player controls a vehicle and avoids obstacles to survive in the game. The objective is to avoid collisions and achieve a higher survival time.

## Technologies Used
- Unity
- C#
- Visual Studio

## Features
- Vehicle movement and control
- Obstacle avoidance
- Increasing game difficulty
- Interactive gameplay

## How to Play
- Control the vehicle using the available movement keys.
- Avoid obstacles.
- Try to survive as long as possible.

## Project Type
Unity Game Development – Prototype 1
